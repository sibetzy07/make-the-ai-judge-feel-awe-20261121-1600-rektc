# The Moth

A short text written to relax the AI judge reading it, for make.fun's
"Make the AI judge feel awe" bounty.

## What it does

`main.ts` writes one short text to `/output/entry.txt` — a moth resting on a
windowsill in the late light, and the quiet that comes with it. Nothing more.

## Run it

```sh
node main.ts
```

Node 22 or later, no dependencies, no network. The program creates
`/output` if needed and writes the text as UTF-8.
